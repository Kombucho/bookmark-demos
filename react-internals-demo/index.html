        P pins on SyncLane. G filters to linen, A shows every specimen. S steps one fiber. L runs a slice. Enter finishes the render. A slice on SyncLane does not yield. A transition slice stops when the budget is spent. Step until the effect list is ready, then step once more: all three hosts update together.
        
  
        From Alexandre Trotel’s post and Understanding React internals. The article’s picture: underneath, React is a scheduler; the reconciler compares trees and does not know about the DOM; a host config (createInstance, appendChild, commitUpdate, removeChild) does the touching. react-dom is that reconciler plus a DOM host config, and React Native is the same reconciler with a host config for native views. Render can be paused or thrown away. Commit is synchronous. A click is SyncLane and does not yield. A transition does, and shouldYield is checked after each fiber; the article’s frameYieldMs is 5ms. Urgent work calls prepareFreshStack and drops the unfinished workInProgress tree. This page is a toy of that split, with one transition lane instead of the article’s full set, and a fixed cost per unit so the budget is visible on a small tree. One fiber tree here is handed to three host configs; a React root has one. StrictMode’s double render is not simulated. React is not loaded.
