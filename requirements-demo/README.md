# Make requirements great

A one-page toy. Paste a messy product note and four obvious rules sort it into problem, users, success, and out of scope.

Open `index.html` in a browser. Nothing to install, and nothing leaves the page.

Inspired by [George Nurijanian’s note](https://x.com/nurijanian/status/2103846806660825532) that soft PRD templates are dead, and that `/make-requirements-great` is free. This page only play-acts a smaller version.
