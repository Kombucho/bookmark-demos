      Example data, invented for this page. Forty-two projects, six skills, no survey behind them. The form is an UpSet plot: intersection size above the matrix, set size beside it, one dot per set in the combination, as set out by Lex, Gehlenborg, Strobelt, Vuillemot, and Pfister (IEEE TVCG, 2014). ComplexUpset is the ggplot2 extension that draws that form with ordinary geoms, and the gallery is the picture this page is working from. This page does not run R. The bars, the dots, and the Venn are counted in the browser from the rows in the script.
