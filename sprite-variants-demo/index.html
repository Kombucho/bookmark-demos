All eight combinations for this style. The highlighted cell is the one above. Each path starts at sprites/pokemon/. A missing picture is a path with no file.

Pixel and Showdown frames use image-rendering: pixelated, so a scaled PNG or GIF stays crisp. Dream World is an SVG and the official art is a smooth PNG, so those two are left to the browser.

25 has a female file in the default set. 1 does not. 1025 has a default PNG, a Dream World SVG, and official art, and no Showdown GIF. The grid is how you see which folders were actually filled in.

The files are PokeAPI/sprites, from @dextune’s post. Each image is loaded from raw.githubusercontent.com. This page does not call the PokéAPI.
