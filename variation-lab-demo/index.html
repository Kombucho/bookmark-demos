    Four theories, then check all four

    A toy list is slow on purpose. Each theory is a candidate, not a conclusion. Checking it runs the experiment in this page and times it with performance.now. The rows are fictional. The timer wraps the JavaScript that builds the list and the layout those reads force. It is not a frame-time trace.

    The twenty variations are the options on the five axes, not twenty separate products. Pinning keeps a mix so you can put it next to another. The simulated rate is the sum of the weights in the page, including a mix term when urgent copy meets poster type, or quiet copy meets the night card. Same mix, same number.
    
    
    From Thorsten Ball’s “How I work with Agents.” The article says not to iterate back and forth with the agent. Instead: “Generate 20 variations and a little page that lets me combine and test them.” The same point for a problem: “Give me 4 theories on why this is slow, then check all four.” This page is that exercise.
