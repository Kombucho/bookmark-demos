A match means the two passes painted the same pixels in this browser. xeet ships its own faces — Chirp subsets, an emoji strike, and fallbacks — because a system font measures and hints differently on each machine, and then the PNG bytes differ. This page uses Segoe UI, system-ui, or the generic sans-serif, whichever is installed. It will not match another computer.
