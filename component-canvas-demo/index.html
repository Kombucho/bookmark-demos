Component canvas

Regular · Soft · Ink

Drag empty board to pan. Scroll to zoom. Spawn one axis, then promote a trial.

Board

The board shows Button, Card, Field, and Badge. They read one token set. A variation changes a single token.

create-canvas puts the components a repository already has on one board, so a variation can sit beside the original and a choice can land back in the shared tokens. Button, Card, Field, and Badge are the components of this page. Density, radius, and emphasis are the token module. Promoting a trial writes one value. The other two stay. No model is called, and nothing is generated.
