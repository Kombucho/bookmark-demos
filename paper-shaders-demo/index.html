Source

From paper-design/shaders and the docs at shaders.paper.design. The vanilla package @paper-design/shaders is vendored at 0.0.82, the version the README asks you to pin while 0.0.x can still break. vendor/paper-shaders/LICENSE is Apache-2.0 and vendor/paper-shaders/NOTICE is the notice that ships with it. Copyright Lost Coast Labs, Inc.

The page imports ShaderMount and the fragment shaders meshGradientFragmentShader, dotOrbitFragmentShader, liquidMetalFragmentShader, paperTextureFragmentShader, flutedGlassFragmentShader, and ditheringFragmentShader. Liquid metal uses a built-in shape (circle, daisy, diamond, metaballs) as the letter mark, with no uploaded logo. Fluted glass refracts sample.png in this folder. The noise texture is the one the package builds in memory. Nothing is loaded from the network.
