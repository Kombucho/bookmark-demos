Search for agents

One switch on a zone. The edge crawls the site, converts each page to Markdown, chunks it, and advertises a search endpoint. The endpoint returns the chunks it found, with scores. It does not write an answer.

Fictional example. Fieldglass, the harbours, the oil grades, and the API are made up. The index is BM25 in this tab, standing in for Cloudflare AI Search. No request leaves the page.

From @Cloudflare’s post and Introducing Search for Agents (25 November 2026). The advertisement is the four agent:* tags, or the same fields as YAML when the request asks for text/markdown. The endpoint is /.well-known/search. GET takes q. QUERY (RFC 10008) takes a plain-text body or {"q":"..."}. Both are safe and idempotent, and both return retrieved Markdown with scores, not a generated answer. The documentation link in the tags is Cloudflare’s Search for Agents docs. This page does not call Cloudflare. The scores are BM25 in the tab, normalised so the top hit is 1.000.
