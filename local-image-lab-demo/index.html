Local image lab

Drop a picture, or start from the one drawn on this page. Three workflows, two steps each, all on a canvas. The file never leaves the tab.

Network requests: 0

The count is fetch, XHR, beacon, and http image URLs seen by this page. Decode, resize, palette, and re-encode stay in the canvas.

Picture

Drawing a sample…

Drop an image here, or choose a file. With no file, the lab uses a picture drawn on a canvas.

Resize, then compress

Step 1 changes the long edge. Step 2 writes JPEG or WebP at the quality you set. Both sizes update as the slider moves.

Sample, then palette

Step 1 draws the resized image down to a small grid. Step 2 cuts that grid into HEX codes. The colors follow the size above.

    Parse, then re-encode

    Step 1 reads the file bytes and lists JPEG markers, including an APP1 segment when one is there. Step 2 draws the pixels and writes a new JPEG. The canvas does not copy APP1.

    Original bytes

      Re-encoded JPEG

      The sample is painted here, exported as JPEG, then given a short EXIF APP1 segment so the strip is visible with no file of your own. A picture you drop keeps the bytes it arrived with. Re-encoding flattens transparency onto white, because JPEG has no alpha.

      The idea is Aimg, from @SubhanHQ’s post: the tools run on the device and the image is never uploaded. This page does not load that site. No library is fetched.
