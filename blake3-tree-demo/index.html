Input

Pattern

The pattern is the official test-vector input: byte i is i mod 251. Lengths on a chunk boundary are 1024, 2048, 3072, 4096, and 8192.

Digest

Flips the low bit of that byte, then hashes again.

Tree

Every chunk can be hashed at the same time. Parents wait until both children exist.

The “no multithreading” walk is the single-threaded order. This page runs the BLAKE3 hash in the browser. It does not run the Servil crate. Nothing is uploaded.
