Anchor

Anchor gotchas

Anchor checks the accounts you name. These four paths step around those checks. Each one starts vulnerable. Turn the fix on and run it again.

Local simulation. No RPC, no wallet, no cluster. Addresses are stand-ins. Owner, signer, and overflow checks are in the Solana accounts demo.

Seed bytes are hashed with no separator, so two arrays can derive one PDA. ctx.remaining_accounts skips Anchor’s account constraints. invoke_signed lends a PDA’s signature to whatever program id was passed. After a CPI, a deserialized account keeps its old fields until reload().

From Zellic, The Vulnerabilities You’ll Write With Anchor, via the bookmarked post. Nothing here contacts a cluster.
