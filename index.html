Twenty-nine tools

Bookmark demos

Each page is the idea itself, running in the browser. No build and no account.

  • Auction anything

    Run a multi-bidder proxy auction. Private maxima, 10% steps, earlier ties, a 48-hour clock, and a 10-minute anti-snipe.
  • Requirements review

    Paste a note and see which of the 18 characteristics fail, including verb + object duplicates across the set.
  • Named embeddings

    Edit the questions, the document scores, and the query vector. Ranking updates, and each match names the dimensions that caused it.
  • Cinematic FUI

    Scroll a HUD of rings, ticks, bars, and readouts. Instanced quads blend into a black-and-white mask, then a shader grades it.
  • Agent change requests

    An agent proposes edits to typed records. Each edit is a change request with a field diff, an author, and comments. Approving commits it.
  • A Lisp image

    Step through a conversation, or type a form. Redefining a function changes the running picture. The world stays.
  • Theme studio

    Hue, contrast, roundness, density, type, and shadow write a token set. The gallery restyles live. Copy CSS and a brief for a coding agent.
  • Constraint gate

    Twelve diffs arrive from an agent and a hurried human. Toggle the type checker, lint, tests, a locked abstraction, and alerts. Each rule stops a diff, or the diff ships and an incident follows.
  • Concept first

    Pick a running app, a sleep app, a plant app, or an Italian deck. Leave the template, choose one of three directions, and run a critique that counts the tells. Refine changes the phone screen.
  • Athanor

    Planetary hours from your sunrise, a host-key sigil and a three-card spread, four pigment stages with measured contrast, a two-tone dither, and a roguelike status line.
  • Paper Mono

    A type bench for the real variable font. Weight, coding ligatures, duospace against strict mono, a narrow space, small arrows, a single-story a, a slashed zero, and fractions.
  • ASCII stage

    Pick a piece from ascii.rest, or edit the embed tag, and watch it play. A switch holds the first frame the way the library does for reduced motion.
  • Brand bot

    Sample mentions of a fictional lantern stream in. A rule book sorts them into amplify, product feedback, needs attention, and ignore, and shows the words that decided it.
  • Animation cost

    The same tray of toasts, twice. A large blur, an animated box-shadow, and a CSS variable written every frame sit beside a small blur, a fading shadow layer, and a transform. Frame time comes from requestAnimationFrame.
  • Solana accounts

    A simulated ledger. Each card is an account with an address, lamports, an owner, an executable flag, and data. Compose a transaction, then turn the program’s checks off and watch which attack drains the vault.
  • Secret files

    Six hanging folders on a cabinet rail. Choose a tab, or use the arrow keys, and that jacket comes forward with a title, a date stamp, and a few lines of notes.
  • Sharded query

    One join crosses a router and four Postgres shards. Step from auth to the rows coming back, then shard orders by customer so each shard can join on its own.
  • Pair token

    Mint and redeem a share of a full-range ETH/NVDA pool. Run swap flow, watch fees pile up, and compound them with a 10% cut. One share is charted against a 50/50 hold and an uncompounded LP.
  • Atomic compose

    Flash-borrow, swap on two venues, and repay. On one L1 the route lands or reverts together. With one venue on an L2, the legs settle apart and a failed leg leaves a position.
  • Flash motion

    Press Record and drag. Clips land on a timeline as offsets, so moving a shape afterward plays the same performance from the new spot.
  • Upgrade authority

    Switch a fictional vault between a single key, a multisig, a council, and locked, then try to replace the binary with a drain.
  • Design & engineering ops

    Person A pulls a branch from Gospel and submits an exploration. Person B sends it back, or it merges. Engineering pulls from its own Gospel, and the approved gospel becomes the app.
  • Anchor gotchas

    Four ways Anchor still lets a bug through: colliding PDA seeds, remaining accounts with no constraints, a CPI that signs with a pool, and a mint supply that stays stale until reload. The fix starts off.
  • LLM knowledge base

    Raw notes on three fictional companies compile into linked wiki pages. A question names the pages it opened. A new note updates the pages it touches and leaves the rest.
  • Flowchart bench

    A Mermaid subset draws nodes, edges, and labels to SVG on every keystroke. A slider builds a large graph so the render time is the thing you watch.
  • Benchmark traps

    Two fictional engines, one simulated client. A cold cache, a working set that fits in RAM, uneven cores, a short run, a closed loop, or a mean headline changes which one wins.
  • Canvas chat

    Pick a prompt, or type your own. The reply is a tool call that puts a map, a drawing, a game, or a sortable ledger on the canvas. Earlier results stay in the history.
  • Frame sound

    Sixteen sounds made of oscillators, noise, envelopes, and filters. A kit is derived from one character and a seed. A looping title card plays each hit on an exact frame.
  • Verify loop

    A toy ledger and its replica pass four happy-path tests. A seeded run reorders, drops, crashes, and skews a clock. The same seed replays the failure, then a scripted fix is applied until the budget is clean.
