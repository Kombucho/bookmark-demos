Bookmark demos

Each page is the idea itself, running in the browser. No build and no account.

  • Auction anything

    Run a multi-bidder proxy auction. Private maxima, 10% steps, earlier ties, a 48-hour clock, and a 10-minute anti-snipe.
  • Requirements review

    Paste a note and see which of the 18 characteristics fail, including verb + object duplicates across the set.
  • Named embeddings

    Edit the questions, the document scores, and the query vector. Ranking updates, and each match names the dimensions that caused it.
  • Cinematic FUI

    Scroll a HUD of rings, ticks, bars, and readouts. Instanced quads blend into a black-and-white mask, then a shader grades it.
  • Agent change requests

    An agent proposes edits to typed records. Each edit is a change request with a field diff, an author, and comments. Approving commits it.
  • A Lisp image

    Step through a conversation, or type a form. Redefining a function changes the running picture. The world stays.
  • Theme studio

    Hue, contrast, roundness, density, type, and shadow write a token set. The gallery restyles live. Copy CSS and a brief for a coding agent.
  • Constraint gate

    Twelve diffs arrive from an agent and a hurried human. Toggle the type checker, lint, tests, a locked abstraction, and alerts. Each rule stops a diff, or the diff ships and an incident follows.
  • Concept first

    Pick a running app, a sleep app, a plant app, or an Italian deck. Leave the template, choose one of three directions, and run a critique that counts the tells. Refine changes the phone screen.
