Slash command

Show me

A patch for Fieldnote, a fictional notes window. The command writes a short pseudo-code slip from the change. Name a part and that node opens. The diff stays on the left so you can see what was left out.

No model is called. The patch, the steps, and the token rule all live on this page. The count is not a model tokenizer: a word of up to six characters is one token, a longer word adds a token every six characters, a punctuation run is one token, and whitespace is free.
